# 气泡 UI 与弹出配置优化设计文档

## 目标

优化 Chrome DeepSeek 划词翻译插件的气泡 UI 和配置入口，让翻译反馈更即时、播放状态更清楚、配置更轻量。

本次优化聚焦两块：

1. 气泡 UI
   - 选中文字后立即弹出气泡。
   - 原文一开始就显示。
   - 翻译加载期间，播放按钮位置显示加载状态。
   - 音标和翻译未返回前显示占位。
   - 翻译返回后，加载状态变成播放按钮。
   - 播放按钮支持播放/暂停两种状态切换。
   - 播放按钮始终居右靠边。
   - 原文、音标、翻译按配置字号自然缩放。

2. 配置体验
   - 点击插件图标直接弹出配置框。
   - 不再跳转设置页作为主要配置入口。
   - 配置项只保留 DeepSeek API Key 和气泡文字大小。
   - 目标语言固定为中文，不再配置。
   - 文字大小默认 `12px`。

## 已确认决策

- 气泡布局采用“紧凑网格”方案。
- 配置弹窗采用“单页紧凑配置”方案。
- 文字大小采用“基础字号”方案：
  - 翻译文字使用配置字号。
  - 原文使用配置字号并加粗强调。
  - 音标使用略小字号，跟随基础字号按比例变化。
- 翻译目标语言固定为 `zh-CN`。

## 气泡交互设计

### 初始状态

用户在普通网页选中非中文文本后，内容脚本立即渲染气泡，不等待 DeepSeek 返回。

初始气泡包含：

- 原文：直接显示用户选中的文本。
- 右侧按钮位：显示加载状态。
- 音标行：显示浅色占位。
- 翻译行：显示浅色占位。

如果选中中文、空文本或无意义文本，仍然直接忽略，不显示气泡。

### 加载成功状态

后台返回翻译结果后，气泡就地更新：

- 原文保持不变。
- 右侧加载状态替换为播放按钮。
- 如果 `phonetic` 存在，音标占位替换为音标文本。
- 如果 `phonetic` 不存在，音标行隐藏或不占主要视觉高度。
- 翻译占位替换为译文。

气泡不重新闪烁创建，避免用户看到跳动感。实现上可以复用现有 `renderTranslationBubble`，也可以拆出 `renderLoadingBubble` 和 `updateTranslationBubble`，以测试和清晰度优先。

### 播放状态

播放按钮有两个状态：

- 未播放/暂停：显示播放图标。
- 播放中：显示暂停图标。

点击播放按钮：

1. 内容脚本向后台发送播放请求。
2. 后台调用 Chrome TTS 播放原文。
3. 气泡按钮状态切换为播放中。

播放中再次点击：

1. 内容脚本向后台发送停止或暂停请求。
2. 后台停止当前 TTS。
3. 气泡按钮状态切换为未播放/暂停。

Chrome `tts` API 更适合实现“停止当前朗读”而不是严格意义上的暂停/恢复。因此 UI 上可以显示为暂停按钮，但行为定义为“停止当前朗读并回到播放态”。如果后续确认 Chrome 环境支持更细粒度暂停能力，再扩展为真正暂停/恢复。

### 加载和错误状态

- 翻译加载中：按钮位显示加载状态，不能点击播放。
- 缺少 API Key：气泡显示配置提示，但主要入口应引导用户点击插件图标配置。
- 网络/API/解析错误：保留轻量错误文案，用户重新选择文本即可重试。
- TTS 不可用：播放按钮禁用或隐藏，不影响译文显示。

## 气泡视觉设计

气泡采用两列紧凑网格：

- 左列：原文、音标、翻译。
- 右列：固定宽度按钮位。

对齐规则：

- 原文、音标、翻译左边界一致。
- 播放按钮始终位于右列，并靠右对齐。
- 右列在加载和播放状态下宽度保持稳定，避免翻译返回时布局跳动。

尺寸规则：

- 气泡宽度继续跟随内容自适应。
- 短词和短语保持紧凑，不留下大块空白。
- 长文本达到最大宽度后换行。
- 最大高度超出后内部滚动。

字号规则：

- 新增配置项 `bubbleFontSize`，默认 `12`。
- 翻译文字字号：`${bubbleFontSize}px`。
- 原文字号：`${bubbleFontSize}px`，字体加粗。
- 音标字号：`max(10, bubbleFontSize - 1)` px。
- 按钮图标尺寸不直接等于文字大小，但可随基础字号轻微放大，避免大字号时按钮显得过小。

## 配置弹窗设计

点击 Chrome 插件图标后打开 popup 配置框。

Popup 内容：

- 标题：DeepSeek 划词翻译。
- DeepSeek API Key 输入框。
- 文字大小滑块或数字输入，默认 `12px`。
- 保存按钮。
- 保存结果状态提示。

不再展示：

- 目标语言选择。
- 清空缓存按钮。
- 复杂说明文案。

目标语言固定为中文，由后台翻译请求使用 `zh-CN`。

原有 options page 可以保留作为兼容入口，也可以在实现计划中改为 popup 复用同一套 UI。推荐优先把现有 options 页面迁移为 popup 页面，减少重复维护。

## 数据结构

现有设置：

- `apiKey`
- `targetLanguage`

新增设置：

- `bubbleFontSize`

推荐类型：

```ts
export interface ExtensionSettings {
  apiKey: string;
  targetLanguage: TargetLanguage;
  bubbleFontSize: number;
}
```

默认值：

```ts
const DEFAULT_TARGET_LANGUAGE = "zh-CN";
const DEFAULT_BUBBLE_FONT_SIZE = 12;
```

存储读取时需要做兼容：

- 如果 `bubbleFontSize` 缺失，使用 `12`。
- 如果 `bubbleFontSize` 不是有效数字，使用 `12`。
- 推荐限制范围为 `12` 到 `20`。

## 消息设计

现有消息：

- `translate-selection`
- `open-options`
- `speak-source`

推荐新增或调整：

- `stop-speaking`
  - 内容脚本请求后台停止当前 TTS。
  - 后台调用 `chrome.tts.stop()`。

可选增强：

- `translate-selection` 响应中不需要携带字号；字号由内容脚本单独读取设置或随初始化读取。
- 内容脚本在每次选中文本时读取最新设置，确保用户刚改字号后新气泡立即生效。

## 文件影响

预计修改：

- `public/manifest.json`
  - 增加 `action.default_popup`。
  - 保留 `storage`、`tts` 权限。
- `src/shared/types.ts`
  - 增加 `bubbleFontSize`。
  - 增加停止播放消息类型。
- `src/shared/storage.ts`
  - 读取和保存 `bubbleFontSize`。
  - 固定默认目标语言为 `zh-CN`。
- `src/background/index.ts`
  - 翻译请求固定使用中文目标语言。
  - 处理停止播放消息。
- `src/content/index.ts`
  - 选区有效后立即渲染加载气泡。
  - 翻译返回后更新为成功气泡。
  - 管理播放/暂停 UI 状态。
  - 读取字号配置。
- `src/content/bubble.ts`
  - 紧凑网格布局。
  - 加载气泡、占位行、播放/暂停状态。
  - 根据 `bubbleFontSize` 设置 CSS 变量。
- `src/options/index.html`
  - 迁移为 popup UI 或作为 popup 入口复用。
- `src/options/index.ts`
  - 移除目标语言配置和清空缓存主入口。
  - 保存 API Key 和文字大小。
- `src/options/styles.css`
  - 改为紧凑 popup 风格。
- 相关测试文件
  - 补充气泡加载态、字号、播放/停止状态、popup 配置测试。

## 测试与验收标准

自动化测试应覆盖：

- `getSettings()` 在缺少 `bubbleFontSize` 时返回 `12`。
- 保存设置时写入 `apiKey` 和 `bubbleFontSize`。
- 目标语言固定为 `zh-CN`。
- 有效选区后立即显示包含原文的加载气泡。
- 加载状态下右侧按钮位显示加载状态。
- 翻译成功后播放按钮替换加载状态。
- 播放按钮点击后切换为暂停状态。
- 暂停按钮点击后发送停止播放消息并切回播放状态。
- 气泡 CSS 使用配置字号。
- Popup 不渲染目标语言选择。

手动验收：

1. 点击插件图标，弹出配置框。
2. 配置框只显示 DeepSeek API Key、文字大小和保存按钮。
3. 设置文字大小为 `12px` 后选中英文，气泡文字较紧凑。
4. 调大文字大小后重新选中英文，新气泡文字变大。
5. 选中英文后气泡立即出现，并立刻显示原文。
6. 翻译未返回时，按钮位显示加载状态，音标和翻译显示占位。
7. 翻译返回后，加载状态变成播放按钮。
8. 点击播放后按钮变成暂停状态，并开始朗读。
9. 再次点击后停止朗读，按钮恢复播放状态。
10. 播放按钮始终在气泡右侧靠边。

## 不包含范围

- 翻译目标语言切换。
- 翻译历史。
- 清空缓存的 popup 主入口。
- 多服务商配置。
- 真正的 TTS 暂停/恢复语音进度。
- 重新设计扩展品牌视觉。

## 设计自查

- 没有保留未确认的目标语言配置。
- 没有把 popup 做成复杂设置页。
- 播放/暂停状态与 Chrome TTS 能力边界一致，暂停按钮行为明确为停止当前朗读。
- 字号设置覆盖原文、音标、翻译，但保留层级差异。
- 气泡加载态满足“选中就弹出来，原文一开始就存在”的要求。
