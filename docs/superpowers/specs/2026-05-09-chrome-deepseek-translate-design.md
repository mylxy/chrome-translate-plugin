# Chrome DeepSeek 翻译插件设计文档

## 目标

开发一个轻量级 Chrome 翻译插件，用于阅读外语网页。MVP 版本在用户选中非中文文本后，使用 DeepSeek Flash 翻译，并在选中文字附近显示一个紧凑的翻译气泡。

第一版只支持普通网页。不支持 PDF、本地文件、Chrome 内置页面或 Chrome 应用商店页面。

## 关键决策

- 插件架构：原生 Chrome Extension Manifest V3。
- 翻译模型：DeepSeek `deepseek-v4-flash`。
- API 地址：DeepSeek OpenAI 兼容接口，`https://api.deepseek.com`。
- 主要交互：用户选中文字后自动出现翻译气泡。
- 默认目标语言：中文，可在设置页修改。
- API Key 处理：用户在设置页手动填写，保存在 Chrome 本地存储中。
- 用户选中中文文本时，插件直接忽略。

DeepSeek 模型和接口信息基于 2026-05-09 核对的 DeepSeek 官方 API 文档：

- https://api-docs.deepseek.com/
- https://api-docs.deepseek.com/api/list-models

## 整体架构

插件分为四个主要部分：

1. 内容脚本
   - 注入普通网页。
   - 监听用户的文本选择。
   - 过滤空文本、无意义文本、中文文本和不支持的选区。
   - 计算选中文字的位置。
   - 渲染和更新翻译气泡。
   - 使用浏览器 `speechSynthesis` 播放原文。

2. 后台 Service Worker
   - 接收内容脚本发来的翻译请求。
   - 从 Chrome 本地存储读取 API Key、目标语言和本地缓存。
   - 优先返回缓存中的翻译结果。
   - 缓存未命中时调用 DeepSeek。
   - 解析并校验模型返回结果。

3. 设置页
   - 保存 DeepSeek API Key。
   - 设置目标语言，默认中文。
   - 提供清空缓存按钮。

4. 共享模块
   - 存储读写工具。
   - 文本规范化和中文检测。
   - 缓存工具。
   - DeepSeek 请求和响应类型。
   - 气泡定位工具。

## 用户流程

1. 用户在普通网页中选中文字。
2. 内容脚本裁剪并校验选区文本。
3. 如果文本是中文、为空或没有实际意义，插件不做任何操作。
4. 如果未配置 API Key，气泡显示简短配置提示，并提供进入设置页的入口。
5. 如果已配置 API Key，气泡先显示在选中文字下方，并进入加载状态。
6. 后台 Service Worker 先查询本地翻译缓存。
7. 如果缓存命中，立即返回缓存结果。
8. 如果缓存未命中，后台 Service Worker 调用 DeepSeek。
9. 气泡更新为原文、可选音标和译文。
10. 用户可以点击原文后面的播放按钮，使用浏览器 TTS 播放原文。

## 气泡设计

气泡采用清爽白卡风格：

- 白色背景。
- 轻量边框。
- 柔和阴影。
- 小圆角。
- 紧凑内边距。
- MVP 阶段不加入额外品牌装饰。

气泡内容顺序固定为：

1. 原文 + 播放按钮。
2. 音标，有可用音标时显示。
3. 翻译结果。

对齐规则：

- 原文、音标和译文使用同一个左边界。
- 播放按钮放在原文后面，不单独占据左侧一列。
- 播放按钮调用浏览器 TTS，不调用 DeepSeek。

尺寸规则：

- 气泡宽度跟随内容自适应。
- 短单词和短语显示为较窄气泡，不留下大块空白。
- 气泡设置最小宽度，避免控件过于拥挤。
- 气泡设置最大宽度，长文本超过后自动换行。
- 气泡高度随内容增长，超过最大高度后在气泡内部滚动。

定位规则：

- 气泡优先显示在选中文字下方。
- 如果下方空间不足，气泡显示在选中文字上方。
- 如果选区靠近视口左右边缘，气泡向内偏移，确保不会被屏幕裁切。
- 当选区消失、用户选择新文本、按下 Escape 或点击气泡外部时，气泡关闭。

## 翻译行为

DeepSeek 请求要求返回结构化结果：

- `sourceText`：用户选中的原文。
- `phonetic`：有用且可靠时返回音标。
- `translation`：翻译成目标语言后的文本。

提示词约束：

- 只翻译用户选中的文本。
- 不扩写解释。
- 不编造上下文。
- 对英文单词和短语，在可靠时尽量返回音标。
- 对长文本、非英文文本或不确定情况，`phonetic` 为空。
- 只返回合法 JSON。

内容脚本只展示实际存在的字段。如果 `phonetic` 为空，则隐藏音标行。

## 语言过滤

MVP 主要服务“阅读外语内容并翻译成目标语言”的场景。

选区过滤规则：

- 空文本：忽略。
- 纯空白：忽略。
- 过短且没有意义的文本：忽略。
- 中文文本：忽略。
- 普通非中文文本：翻译。
- 很长的非中文文本：可以翻译，但气泡仍受最大宽度和最大高度限制。

中文检测应该保守处理：如果选中文本包含明显的 CJK 字符，并且整体看起来是中文内容，插件应直接忽略。

## 本地缓存

插件在浏览器本地维护翻译缓存，用于减少重复调用 DeepSeek。

缓存规则：

- 只缓存单词和短语级翻译结果。
- 不缓存长句或段落翻译。
- 缓存 key 使用规范化后的原文和目标语言。
- 规范化会去掉首尾空格，并对英文做小写处理。
- 示例 key：`learning::zh-CN`。
- 用户选中文字后，后台 Service Worker 先查缓存，再决定是否调用 DeepSeek。
- 缓存命中时立即返回。
- 缓存未命中时调用 DeepSeek，成功后写入缓存。
- 最多缓存 100 条。
- 写入第 101 条时，删除最早写入的那一条。
- API Key 不参与缓存 key，也不会写入缓存值。
- 设置页提供清空缓存按钮。

## 配置项

以下设置保存在 Chrome 本地存储中：

- `apiKey`：DeepSeek API Key。
- `targetLanguage`：目标语言，默认 `zh-CN`。
- `translationCache`：最多 100 条翻译缓存。

如果缺少 `apiKey`，气泡显示配置提示，并提供进入设置页的入口。

## 错误处理

界面保持轻量，并提供可恢复路径：

- 缺少 API Key：在气泡中显示配置提示。
- 网络失败：显示简短错误信息。
- DeepSeek API 报错：显示简短错误信息。
- 返回结果不是合法 JSON：显示简短错误信息。
- TTS 不可用：本次交互禁用或隐藏播放按钮。

用户可以通过重新选择文本来重试。

## 测试与验收标准

自动化测试应覆盖：

- 存储读写工具。
- 中文检测。
- 选区过滤。
- 缓存 key 规范化。
- 缓存写入和超过 100 条后的最早项淘汰。
- DeepSeek 返回结果解析。
- 气泡在下方、上方和视口边缘的定位。

手动验收项：

- 选中英文单词后，紧凑气泡显示在选区下方。
- 选中英文短语后，显示原文、播放按钮、音标和译文。
- 选中英文句子后，能够翻译，并且长内容可以正常换行。
- 选中中文文本时，插件不做任何操作。
- 在视口底部附近选中文字时，气泡显示到选区上方。
- 在视口左右边缘附近选中文字时，气泡保持完整可见。
- 短文本气泡不会留下过多横向空白。
- 未配置 API Key 时，气泡显示配置提示和设置入口。
- 重新选择已缓存的单词时，应快速返回结果，不再请求 DeepSeek。
- 缓存超过 100 条后，最早缓存的内容被删除。

## MVP 不包含的范围

- 整页翻译。
- PDF 翻译。
- 本地文件翻译。
- Chrome 内置页面支持。
- Chrome 应用商店页面支持。
- 多翻译服务商。
- 账号同步。
- 翻译历史界面。
- 在气泡中临时切换目标语言。
